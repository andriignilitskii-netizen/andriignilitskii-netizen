### API contracts and tooling

[**api-contract-diff**](https://github.com/andriignilitskii-netizen/api-contract-diff) — a Python CLI and GitHub Action for checking OpenAPI 3.1 changes. It follows local references, applies separate request/response rules, and reports cases that need manual review. CI reports are saved even when the contract check fails.

[![API contract tests](https://github.com/andriignilitskii-netizen/api-contract-diff/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/andriignilitskii-netizen/api-contract-diff/actions/workflows/ci.yml)
